# Day 08 - Strings

- String methods such as .lower() and .strip() return a new string, the original does not change.
- " ".join(list) glues the items using the text before the dot; s[::-1] reverses a string.
- Forgetting () after a method (s.lower) does not run it, it only refers to the method.
- f"{name}" puts the value of a variable inside a string.
